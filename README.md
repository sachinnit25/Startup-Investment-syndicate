## What This Does

The **Startup Investment Syndicate** contract enables a group of investors to anonymously pool capital towards a startup funding goal.

Each investor submits a **zero-knowledge proof** that they have committed a valid, non-zero amount. The contract tracks the total pooled funds and publicly announces when the funding goal is reached — **without ever revealing individual investor identities or exact investment amounts**.

Key behaviours:
- Any investor can commit funds by providing a **private secret key** and an investment amount — both stay off-chain
- The on-chain ledger only stores **aggregate data** (total committed, investor count, goal status)
- A ZK proof is generated locally and verified on-chain — no raw private data is ever submitted
- The `disclose()` call deliberately reveals only the **goal-reached boolean**, nothing else
- Investors can verify syndicate status without exposing who invested or how much

## Privacy Model

| Layer | Data | Visibility |
|-------|------|------------|
| **PUBLIC** | `total_committed` — aggregate funds pooled | ✅ On-chain, visible to all |
| **PUBLIC** | `investor_count` — number of investors | ✅ On-chain, visible to all |
| **PUBLIC** | `goal_amount` — target fundraising goal | ✅ On-chain, visible to all |
| **PUBLIC** | `goal_reached` — whether goal has been met | ✅ Disclosed via `disclose()` |
| **PRIVATE** | `investor_secret` — 32-byte identity key | ❌ Never on-chain, ZK proof only |
| **PRIVATE** | `investment_amount` — exact contribution | ❌ Never on-chain, ZK proof only |

**What the user PROVES without revealing:**
- They hold a valid investor identity (secret key)
- Their investment amount is greater than zero
- The syndicate goal-reached status (deliberately disclosed)
- Individual identity and exact amounts remain completely hidden

## Prerequisites

Before running locally, ensure you have:

- [ ] Node.js v22 (`node -v` → `v22.x.x`)
- [ ] Docker Desktop installed and **running**
- [ ] WSL2 with Ubuntu (for Compact compiler on Windows)
- [ ] Compact compiler v0.31.1 installed via:
  ```bash
  curl --proto '=https' --tlsv1.2 -LsSf https://github.com/midnightntwrk/compact/releases/latest/download/compact-installer.sh | sh
  compact update 0.31.1
  ```
- [ ] A funded wallet on the Midnight Preview network

## Setup

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/Startup-Investment-syndicate.git
cd Startup-Investment-syndicate

# 2. Install dependencies
npm install

# 3. Start the proof server (Docker must be running)
docker run -d -p 6300:6300 --name proof-server midnightnetwork/proof-server

# 4. Compile the contract (WSL / Linux / macOS)
compact compile contracts/counter.compact managed/counter

# 5. Deploy to local devnet (via mn-demo scaffold)
cd mn-demo
npm run setup   # spins up local devnet
npm run deploy  # deploys contract, prints address
```

## Circuits

The contract exposes 3 circuits:

| Circuit | Inputs | Privacy |
|---------|--------|---------|
| `initialize(goal)` | Goal amount | Public |
| `commit_investment(investor_secret, investment_amount)` | Secret key + amount | **Private** |
| `get_status()` | None | Read-only |

## Initial Idea

This project was inspired by the growing need for **private, trustless investment coordination** in the startup ecosystem. Traditional investment syndicates require intermediaries and expose sensitive financial information. By leveraging Midnight's zero-knowledge proof infrastructure, investors can participate in funding rounds while maintaining complete anonymity — the syndicate can provably reach its goal without any participant ever knowing who else invested or how much they contributed. This creates a fairer, more accessible investment mechanism particularly useful for early-stage startups seeking capital without revealing their investor list prematurely.
